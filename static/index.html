Contract RAG Agent — 智能合同审查助手

👋 你好！我是您的合同审查助手

本助手基于 RAG（检索增强生成）技术构建，能够基于已上传的合同条款回答您的问题。


我能帮您：

  • 上传并自动解析 PDF / Word 合同文件
  • 基于合同条款回答您的法律问题（答案带原文引用）
  • 自动检测合同中的潜在风险条款并给出修改建议
  • 对比两份合同的条款差异，评估修改风险

请先通过左侧「📁 上传合同」上传一份合同文件，或直接输入问题开始对话。


📋 使用须知
1. 本助手专注于合同审查与条款分析，不支持通用闲聊。与合同无关的提问可能无法获得理想回复。
2. 风险检测与合同比对每次返回独立的会话 ID，提问时请围绕当前操作的结果进行追问，不建议在一次对话中穿插追问不同功能的检测/比对结果，以免上下文错乱。
3. 如发现回答未按预期引用合同条款，请尝试更换提问角度或检查合同是否已上传并解析完成。
